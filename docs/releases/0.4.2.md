This update adds compatibility with the locally tested SkullLoader build for Skullgirls 3.7.20 on Windows. The manager rejects SkullLoader v0.5 for that game executable, including previously cached copies.

- **Windows x64** — extract the ZIP and run `SkullgirlsModManager.exe`. Requires the .NET 9 Desktop Runtime.
- **Linux x64** — extract the self-contained archive and run `./SkullgirlsModManager`.

The Windows loader is supplied separately. The accepted 3.7.20 DLL is a local test build of SkullLoader commit `93798f8`. See the third-party notices for its checksum. [Upstream test commit](https://github.com/Skullgirls-Communitys-Cut/SkullLoader/commit/93798f8b13c0140acb2a3d2c7ce925d8f85f2e30)

The native Linux manager is included. Its protected-archive support still requires the previously verified native game executable. Native Linux Skullgirls 3.7.20 has not been verified for protected-archive mods.
