Optional components can now be toggled within a single mod on Windows and Linux.

- **Options…** appears beside mods that declare optional components. Choose components, save, then Preview and Apply.
- Selections persist across restarts. Windows named profiles and mod updates retain component selections.
- Import AOTC standalone ZIPs directly. Replacement checksums are verified; the optional Soviet announcer is off by default. Installer scripts and the loader DLL are excluded from the converted mod. Set up mod support separately when required.
- Authors can declare optional file or directory groups in `mod.json`; see the user guide.
- `Build-All.ps1 -Test` builds both platform targets and runs shared fixture tests.

**Downloads:** Windows users should extract the Windows ZIP and run `SkullgirlsModManager.exe` (.NET 9 Desktop Runtime required). Linux x64 users should extract the `.tar.gz` and run `./SkullgirlsModManager`; the runtime is included. Matching source and SHA-256 checksums are included.

Linux asset editing, audio previews, package updates and named profile controls remain available through the Windows interface only. Keep the manager's backup directory. No game files, mod assets, settings or user backups are distributed.
