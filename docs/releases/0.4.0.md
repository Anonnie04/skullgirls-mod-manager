Native Linux support is now available alongside the existing Windows app.

- Art Deco Linux interface with a skull crest, geometric borders and burgundy-and-gold styling.
- Automatic game discovery for standard, Snap, Flatpak and additional Steam libraries.
- Import existing replacement-mod ZIPs unchanged; manage enable settings and load order, review changes, apply, restore and recover with verified backups.
- Reversible native archive support for the audited Linux executable documented in `docs/NATIVE_SUPPORT.md`. Unknown executable builds are rejected.
- AOTC 0.15.1 was installed and confirmed working in the native Linux game. Its ZIP remains unchanged.

**Downloads:** Linux x64 users should extract the `.tar.gz` and run `./SkullgirlsModManager`; the .NET runtime is included. Windows users should extract the Windows ZIP and run `SkullgirlsModManager.exe` (.NET 9 Desktop Runtime required). Matching source archives and SHA-256 checksums are included.

The Linux frontend currently supports archive/loose-artwork installation and recovery. Asset editing, audio previews, package updates and named profile controls remain in the Windows frontend. Windows DLL plugins need native ports.

Keep the manager's backup directory. On Linux, **Restore originals** restores the archives and the original native executable. No game files, mod packages, user settings or user backups are distributed.
